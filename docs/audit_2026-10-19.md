# Audit fix log — 2026-10-19

This file records the defects found by an independent audit of the CERPS
framework (six-way literature review + ten numerical cross-checks, all
reproducible from the scripts listed at the end), and the fixes applied.
The regression tests are `tests/test_audit_fixes.py` (82 assertions).

---

## 1. `simulator.py` — phenotype label updated for all cells

**Defect.** `run()` called `classify_legacy` for every cell at every step.
The paper's numerical scheme ("If the cell is **in the resting phase**,
update the phenotype"), the released C++ `UpdateCellType`, and
`reproduction/hsl2024/reference_sim.py` (`ctype = np.where(resting,
new_type, ctype)`) all freeze the phenotype from proliferation entry to
mitosis.

**Effect.** A proliferating SC cell that drifts is re-classified, so the
SC count `Q` used by `beta_SC = beta0*theta0/(theta0+Q)` drops during the
cycle, raising `beta_SC` and inflating SC self-renewal.

**Measurement** (3 runs, 4000 h, window t >= 2000 h):

| rule | SC->SC | SC->TA1 | SC->TA2 |
|---|---|---|---|
| before (all cells) | 76.7201 | 11.8748 | 11.4051 |
| **after (resting only)** | **74.2281** | **12.7773** | **12.9946** |
| `hsl2024` engine, same protocol | 74.2340 | 12.6734 | 13.0926 |
| difference | **-0.006 pp** | +0.104 | -0.098 |

The `div_int` / `div_count` reset is likewise restricted to
`resting & (label == 0)`, matching `reference_sim.py`.

## 2. `grn.py` — cross-regulation threshold averaged two genes

**Defect.** `S_rep[i,j] = 0.5*(s[i]+s[j])`.  Eq. (1) of the paper uses the
*source* gene's threshold: `+ b_1 * s_2^n/(s_2^n + x_2^n)`.

**Effect.** The exact reduction to Eq. (1) failed whenever `s_1 != s_2`
(max |dx| = 0.12 over 400 steps).  The paper's Fig. 10 sweeps six
parameter series, one of which is `s_1 = 0.55`, so legacy mode could not
reproduce that figure.

**Fix.** `S_rep[i,j] = S_act[i,j] = s[j]` (diagonal placeholders stay 1.0).

**Measurement.** Exact reduction (max |dx| < 1e-9) now holds for
`s1=0.3/s2=0.7`, `s1=0.7/s2=0.3`, `s1=0.55`, `k1=1.1`, `alpha1=0.44`,
`rho1=0.11`, `b1=1.1`, `a_tf=0.3`, `n=2`, and the default.

## 3. `spatial.py` — paracrine field: silent CFL clamp and periodic boundaries

**Defect (a).** `c = min(D*dt/h**2, 1.0/6.0)` clamped the diffusion number
to the 3-D von Neumann limit instead of sub-stepping, so the *nominal*
diffusivity was silently replaced.  With the default configuration
(D=25, dt=0.25, h=4) the field ran at D_eff = 10.67 — 43% of the
requested value.

**Proof.** Steady-state fields: `D=25, dt=0.25` (clamped) was
**bit-identical** to `D=10.667, dt=0.25` (unclamped, max relative
difference 0.0e+00), and differed from `D=25, dt=0.10` (unclamped) by 53%.

**Fix.** The step is sub-cycled: `n_sub = ceil(Fo/(1/6))`, each sub-step
using `Fo_sub <= 1/6`.  The nominal `D` is now honoured, and the scheme is
dt-consistent (equal sub-dt gives bit-identical fields).

**Defect (b).** The Laplacian used `np.roll`, i.e. periodic boundaries,
while the cell domain is a reflecting sphere.  A cell at the boundary saw
a "ghost" signal equal to 8% of the true value from the opposite side.

**Fix.** Reflecting (zero-flux) boundaries via edge padding.  The ghost
signal is now 1e-6 of the true value.

## 4. `rates.py` — TA-side switch used the same threshold as the SC side

**Defect.** `HnS = hill(1-S, K, p)` with the same `K` as
`HS = hill(S, K, p)`.  The two switches therefore fire at `S = K` and
`S = 1-K` respectively.  At the original hard-coded default
`K_switch = 0.5` these coincide (`1-K == K`) and the defect is invisible;
as soon as `K` is derived from the legacy boundary (0.25 for two genes,
0.125 for three) it is not.

**Effect.** At `K = 0.125` a stem-like cell with `S = 0.5` received
`kappa = 2*kappa0` (the TA removal rate) instead of `kappa0`.  In the
3-gene example this drove the population to extinction (n = 0 for every
seed and every `theta0` tested).

**Fix.** `HnS = hill(1-S, 1-K, p)` — the complementary threshold — so both
sides fire at the same `S = K`.  The sharp limit still recovers Table 1
exactly (SC: beta = 0.03980, kappa = 0.0100, tau = 4.00; TA: beta =
0.0400, kappa = 0.0200, tau = 2.00), and the 3-gene example regains its
four-phenotype homeostasis (3871 cells: 344 all-on, 844/1336/1347
single-gene-high).

## 5. Orthogonality: kernels are now controlled noise-only variants

**`cpg` kernel.** The mechanistic maintain/de-novo rule has the affine
mean map `p_m*v + p_d*(1-v)` (fixed point 0.143), whereas beta and
gaussian use the Hill map `phi` (fixed point 0.132).  Switching kernels
therefore changed the deterministic drift, so cross-kernel comparisons
were not controlled experiments.

* New default `cpg_mode="moment"`: the per-site marking probability is
  `phi(v)`, giving `E[u] = phi(v)` and `Var[u] = phi(1-phi)/M`.  With
  `cpg_sites = m0+1 = 61` this matches the beta kernel in **both**
  moments.
* `cpg_mode="mechanistic"` keeps the classical rule, with the mean-map
  difference documented in the docstring and asserted by a test.

**`gaussian` kernel.** Truncating a normal to `[0,1]` necessarily shifts
its mean: at `phi = 0.081, sigma_g = 0.30` the true truncated mean is
0.270.  The old folding (`|z| % 2`) gave 0.248 — also wrong.  The kernel
now solves for the pre-truncation mean that makes the truncated mean
exactly `phi(v)` (bisection on the monotone map, ~25 iterations, early
exit).  Measured mean error is now <= 1.3 Monte-Carlo standard errors
across `sigma_g in {0.045, 0.15, 0.30}` and `v in {0.02, 0.1, 0.5, 0.9}`.
Cost: ~1.4 ms per call at realistic array sizes (~20% overhead on the
gaussian kernel; the default beta kernel is unaffected).

**`K_switch`.** Default changed from `0.5` to `None`, which derives
`K = prod_j H+(x_threshold)` so the continuous classification boundary
coincides with the legacy `x_threshold` on the diagonal.  (The two rules
still disagree off the diagonal — a box cannot be represented exactly by
a single product threshold; ~8% of the (x1,x2) plane at the aligned K.)

**`division.alpha`.** New continuous partitioning-noise strength
(Soltani et al. 2016, PLoS Comput Biol 12:e1004972, Eq. 5):
`Var[x_daughter|x] = alpha*x*(1-f)/f`.  `alpha = 0` deterministic, `1`
independent binomial, `>1` beta-binomial (clustered), `<1` variance-
matched normal.  Verified: alpha = 0/0.5/1/2/4 give variances
0/0.00252/0.00499/0.01000/0.01996 against the theoretical
0/0.00250/0.00500/0.01000/0.02000.

## 6. Interface

* `CERPSConfig.rec_tran_from` (default 0) discards transitions before the
  given time, so `sim.transitions` is directly comparable with the
  paper's Table 3 (which counts only t > 2000 h).  Verified: the filter
  removes the transient and does not change the dynamics.
* `Space.relax(dt)` is now time-step consistent: the overlap decays as
  `exp(-dt/tau)` with `tau = relax_time` (derived from the legacy `relax`
  at a nominal dt = 0.25 h, reproducing the old behaviour exactly there).
  Two dt/2 steps now equal one dt step.
* `SpaceConfig.normalize_source` optionally divides the field injection by
  `h^3` for true concentration units.

## 7. New experiment layer: `cerps/batch.py`

`sweep` / `run_one` / `aggregate` / `report` (parameter sweeps, multi-seed
replicates, checkpoint-resume via `results.jsonl`, mean/std across seeds),
`homeostasis` / `transitions` (statistics with the paper's definitions),
`health_check` (CFL number and dt-halving convergence), and `validate`
(warnings for configurations that silently invalidate a comparison:
`alpha` ignored under `partition="exact"`, `cpg_sites != m0+1`, a
`K_switch` that moves the classification boundary, `rec_tran_from = 0`,
and a paracrine Fourier number above the CFL limit).

## 8. Documentation

* `epigenetics.py` cited Dodd 2007 / Probst 2009 / Zhao 2021 for the
  activity-dependent writing ODE.  None supports it: Dodd 2007 is an
  exact combinatorial nucleosome model with no beta kernel and no such
  ODE; Probst 2009 (Nat Rev Mol Cell Biol 10:192) is a qualitative review
  with no rate equations; Zhao 2021 (iScience 24:102732) states in its
  limitations "we do not take into account the transcription processes".
  Replaced by Berry, Dean & Howard 2017 (Cell Systems 4:445 — erasure
  rate proportional to the transcription rate) and Miyamoto, Furusawa &
  Kaneko 2015 (PLoS Comput Biol 11:e1004476 — slow epigenetic variable
  relaxing toward a transcription-dependent target).  A note warns that
  the sign of the coupling must be reversed if `u` is a repressive mark.
* `params.py` / `docs/protocol_notes.md` record that the paper's Table 2
  lists `m2 = 1.0` while its own simulations (Sec. 3.4.2, Sec. 3.5,
  Fig. 12, and the released C++ sweep) use `m2 = 0.8`; 0.8 is what
  reproduces the published Table 3 and is what we use.
* `grn.py` docstring corrected (it described "additive regulation" while
  the default is product) and the product-form precedent (Duddu et al.
  2026, J. R. Soc. Interface 23:20251065, Eq. 4.5) cited.
* `example_multigene.py` plot labels corrected: for G > 2 the recorder's
  `ta2` field holds label 3 (X3-high) and `other` holds label 2 (X2-high).
* `requirements.txt` pins `numba==0.65.0` (the RNG stream inside the
  `@njit` kernel is not bit-stable across releases; the archived Table 3
  data was generated with it).
