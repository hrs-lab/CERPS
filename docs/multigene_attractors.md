# 3-基因全互抑示例：吸引子结构与 Duddu (2020) 统计对照

> 对应审查报告问题 P2-#14。目标：报告"全开（all-on）"与"双阳（double-positive）"
> 态的参数区间，并对照 Duddu et al. (2020, *J R Soc Interface* 17:20200631)
> 的三节点互抑 RACIPE 吸引子统计（单阳 ~60%、双阳 ~36%、三阳 ~4% 且被作者排除）。

## 方法

- 网络：3 基因全互抑（`GRNConfig(n_genes=3)`），高斯遗传核（`kernel="gaussian"`），
  连续速率（`rate_mode="continuous"`）——与 `examples/example_multigene.py` 一致。
- 扫描变量：每基因基础表达/抑制强度 `b_base ∈ {0.8, 1.5, 3.0}`（其余用示例默认值）。
- 每种配置 3 个种子（seed 1/2/3），`n_init=100`，`max_time=1200 h`。
- 终态分类：以 `x > 0.5` 计每细胞高表达基因数 `n_hi`：
  `n_hi==3`=全开（干性样），`n_hi==2`=双阳，`n_hi==1`=单阳（3 个变体），`n_hi==0`=全低。
- 同时记录离散 `label==0`（全开）计数为对照。

## 关键发现

1. **稳态由单阳态主导（~93%）**，且三个单阳变体大致均衡；**全开（干性样）态仅占 ~0.5–1%**，**双阳态稳定存在（~6–7%）**。
2. **示例文档字符串与实测不符**：`example_multigene.py` 声称"群体稳定在四种表型——全开干性态 + 三种单基因高态"。实测全开态近乎消失，且存在一个文档未提及的、持续 ~7% 的**双阳尾态**（双阳细胞在 `classify_legacy` 中保留"前一标签"，故在 `label`-based 计数中不可见，只在 `n_hi` 分类中暴露）。
3. **离散 `label==0` 计数系统性高估真实全开比例**（如 b=0.8,s=1：label=0 计 136 但 n_hi=3 仅 11）。原因：连续模式下标签在增殖期冻结、仅在静息期重评，使许多已偏离全开的细胞仍带 SC 标签。**这一标签–真值 gap 在 3 基因连续模式中不可忽略**，做定量 SC 占比时须用 `x` 真值而非 `label`。
4. **种子间总量方差极大（238–6228）**：1200 h 内 3 基因连续系统远未到达稳态（2 基因 legacy 都需 2000–4000 h 才进入 homeostatic 窗口）。上表比例应读作"发育/瞬态"而非真吸引子；要得到收敛吸引子分布需 ≥2000–4000 h 并重做扫描。

## 与 Duddu (2020) RACIPE 统计对照

| 拓扑 | Duddu RACIPE | 本 CERPS 示例（瞬态, 1200h） |
|---|---|---|
| 单阳 | ~60% | ~93% |
| 双阳 | ~36% | ~7% |
| 三阳（全开） | ~4%（被排除） | ~0.5% |

**分布方向相反**：Duddu 以双阳为主体、三阳极小；CERPS 以单阳为主体、双阳与三阳都更小。这并不矛盾——Duddu 在参数空间上广采样且为离散布尔/阈值网络，而 CERPS 用固定参数 + 连续速率 + 高斯核。但结论是：**当前 3 基因全互抑网络并不能稳健复现"全开=干性、单阳=定向"的隐喻**（全开态占比过低）；这与审查报告 §3.3 的文献张力判断一致。

## 建议（供机制对比实验采用）

- 若目标是建模"干性=全开、子代=单阳"，需**调整网络**：加入弱自激活边（`c_act`）或改用"互激活核心 + 互抑命运基因"分层结构（Boyer 2005 / Chickarmane 2006），而非纯互抑。
- 在报告任何 3 基因吸引子分布前，先做 **≥2000–4000 h 收敛扫描**，并以 `x` 真值（非 `label`）分类。
- 修正 `example_multigene.py` 文档字符串，明确写出"实际以单阳为主、含 ~7% 双阳尾、全开态极小"，避免误导。
- 未来工作：完整扫描 `s_self`、`c_act`（自激活）、四种遗传核，绘制吸引子占比相图。
